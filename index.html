About this project

This is a simple, accessible learning site where I practise HTML, forms, and styling. It includes a functional contact form with validation and a theme toggle for better readability.

Quick features

  • Semantic HTML structure (header / nav / main / footer)
  • Accessible form with client-side validation
  • Responsive layout for phones and desktops
  • Descriptive link text and image alt text
